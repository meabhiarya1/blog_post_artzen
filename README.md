# Blogging Platform

This is a full-stack blogging platform built with React, Node.js, Express.js, and MongoDB. It allows users to create, read, update, and delete blog posts. Users must sign up and log in to create and manage their own blog posts.

## Features

* User authentication and authorization
* Create, read, update, and delete blog posts
* Responsive design for mobile and desktop devices

## Technologies Used

* Frontend: React, React Router, Tailwind CSS
* Backend: Node.js, Express.js, MongoDB, Mongoose
* Database: MongoDB
* Authentication: JSON Web Tokens (JWT)

## Installation

* Clone the repository
* cd client and then Install dependencies: `npm install` and then create .env file 
    -- VITE_API_URL = backend url
* cd server and then Install dependencies: `npm install` and then create .env file 
    -- PORT= any port
    -- MONGODB_URI= mongo db uri
    -- JWT_SECRET= secretkey
* Start the server: `npm start`
* Start the client: `npm run dev`

## Usage

* Sign up for an account and log in to create and manage your own blog posts
